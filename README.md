# Учёт трудозатрат и стоимость работ по проектам

Тестовое задание fullstack: .NET 8 + MongoDB + React/TypeScript.

## Запуск (dev)
1. `docker compose up -d mongo`
2. `dotnet run --project backend/Timesheet.Api`
3. Swagger: http://localhost:5000/swagger

Статус: в разработке. Итоговая инструкция будет дополнена.
